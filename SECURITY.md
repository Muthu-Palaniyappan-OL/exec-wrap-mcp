# Security policy

`exec-wrap-mcp` executes arbitrary programs with the privileges of the user who runs it. Read the
[Security section of the README](README.md#security) before deploying it.

## Reporting a vulnerability

Please report privately through GitHub:
**Security tab → "Report a vulnerability"** on
<https://github.com/Muthu-Palaniyappan-OL/exec-wrap-mcp/security/advisories/new>.

Do not open a public issue for security problems. You can expect an acknowledgement within a few days.

## Supported versions

Only the latest release receives security fixes.
